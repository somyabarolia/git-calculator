# Git Calculator

A beginner-friendly calculator project built while learning Git and GitHub.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Web-based calculator interface

## Project Structure

- `calculator.py` - Python calculator
- `operations.py` - Mathematical operations
- `index.html` - Web page structure
- `style.css` - Web page styling
- `script.js` - Calculator functionality

## Technologies

- Python
- HTML
- CSS
- JavaScript
- Git
- GitHub

## How to Run

For the Python Calculator:

Python calculator.py

For the web Calculator:

Open index.html in your browser.
